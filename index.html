04. Open Source

RubyGems Source Code

app_pulse

app_pulse is a lightweight, production-safe Ruby gem that tracks HTTP request lifecycle signals using Rack middleware. It stores raw, trustworthy request data in rotating files (CSV / JSON / Text) for offline analysis.

It is not an APM, optimizer, or dashboard — it is a signal collector. Designed to collect data first and derive insights later.

  • Tracks request duration, status, and failures
  • File-based storage with daily rotation
  • Configurable sampling & slow request thresholds
  • No database, no Rails internals, no side effects
  • Compatible with Rails, Rack, Sinatra
Ruby Rack Middleware Observability Instrumentation
